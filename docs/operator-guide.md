# Operator Guide

## First Deployment

1. Define the operator's service area and case-intake process.
2. Define consent and confidentiality/purpose categories.
3. Run synthetic operating cases.
4. Enable human-reviewed sign-off for `:high`/`:safety-critical` actions
   (confidentiality-concern flags, over-cost supply orders).
5. Measure operating outcomes and audit coverage.

## Minimum Production Controls

- consent and disclosure log
- confidentiality-escalation path
- provenance for all operating records
- human review for confidentiality concerns and high-cost procurement
- audit export for all gated actions

## Certification

Certified operators must prove that the governor gates every
safety-critical/confidentiality-critical action, that no op outside the
closed allowlist can be proposed or committed, and that confidentiality
risks always escalate to humans.
